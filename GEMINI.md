# Reglas del Espacio de Trabajo

- **Formato obligatorio de documentos (`.docx`):** Cada vez que el usuario solicite crear un documento, guía de ejercicios, guía de materia, resumen, apunte o evaluación, **siempre** debes generarlo como un archivo Microsoft Word (`.docx`) utilizando la skill `documentos-docx` (`.agent/skills/documentos-docx/SKILL.md`).
