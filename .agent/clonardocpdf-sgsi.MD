description: "Crea copias de documentos PDF en una carpeta específica, renombrándolos según un formato de fecha y hora. Usar la simbología del sistema internacional en las operaciones y ejemplos

1. **Encontrar**: Busca el archivo PDF deseado.
2. **Clonar**: Crea una copia exacta del archivo.
3. **Renombrar**: Cambia el nombre del archivo según el formato "AAAA-MM-DD_HH-MM-SS_nombreoriginal.pdf".

Proceso

1. **Identificar la carpeta destino** donde se guardarán las copias.
2. **Especificar el nombre base** del archivo (sin extensión).
3. **Ejecutar la acción** de clonar y renombrar.
4. **Crear el contenido del documento con simbologia numerica y matematica en ejercicio de operaciones y ejemplos, el sistema internacional de unidades  y sus prefijos**

Ejemplo:

Si queremos clonar el archivo "tarea1.pdf" en la carpeta "copias" con el nombre base "tarea1", el agente realizará los siguientes pasos:

1. Buscar el archivo "tarea1.pdf".
2. Crear una copia exacta del archivo.
3. Renombrar la copia a "AAAA-MM-DD_HH-MM-SS_tarea1.pdf" en la carpeta "copias".
